5. JSON "CONTRACTS" -- MODULE INTERFACES
----------------------------------------------------
Each module emits and receives a defined JSON shape.
These are the contracts the team must not break.

5a. ASR -> (downstream)
    Input : audio file path (wav, 16 kHz mono)
    Output:
    {
      "text": "<transcript in Devanagari>",
      "language": "hi",
      "duration_s": 4.2,
      "speaker_id": "spk01"
    }

5b. Intent Classifier -> (downstream)
    Input : ASR "text" string
    Output:
    {
      "intent": "pest_disease",
      "crop": "tomato",
      "entities": ["whitefly"],
      "confidence": 0.91
    }

5c. Retriever (RAG) -> LLM
    Input : intent + crop + entities + query text
    Output:
    {
      "passages": [
        {"id": "S001", "text": "...", "score": 0.92}
      ],
      "tool_facts": {
        "weather": { "temp_c": 28, "rain_mm": 12 },
        "market":  { "crop": "tomato", "price_per_kg": 18 }
      }
    }

5d. LLM -> Trust Filter
    Input : retriever output + prompt
    Output:
    {
      "answer_text": "<Hindi answer>",
      "sentences": ["sent1", "sent2"],
      "sources": ["S001", "S003"]
    }

5e. Trust Filter -> TTS / UI
    Input : LLM output
    Output:
    {
      "final_answer": "<Hindi answer, possibly trimmed>",
      "confidence": 0.95,
      "escalate": false,
      "faith_score": 0.99
    }

5f. TTS -> Audio output
    Input : "final_answer" string
    Output:
    {
      "audio_path": "output/answer_0001.wav",
      "duration_s": 6.1
    }
